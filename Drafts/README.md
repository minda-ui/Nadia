# Drafts

Outward-facing work Nadia has prepared but not sent — quotes, customer replies — awaiting a human's
review and release, per `../CHARTER.md` §3. Nadia never sends from here herself.

- **What belongs here:** a quote or reply drafted for a specific enquiry, named
  `YYYY-MM-DD_<enquiry-id>_<short-description>.md`, stating clearly what it is and what it would commit.
- **Nothing stays here once released or superseded.** A sent draft's outcome (sent as-is, edited, or
  declined) is logged in the CRM row (`Next action`) and the relevant `Outputs/change-log` entry; the
  draft file itself moves to `../Archive/` once actioned, per house rules §2 (archive-then-recreate,
  never delete).
- This file is a folder guide, not source material. Registered `skipped` in `Outputs/kb-registers.md`'s
  Processed items table, per the same convention as `Raw/README.md` and `Outputs/README.md`.
